# Definições de classes estrangeiras

Aqui ficam as definições de classes estrangeiras, ou seja, aquelas que não são nativas do Delégua, mas que podem ser usadas em programas escritos em Delégua. Essas definições são usadas para permitir a interoperabilidade entre o código escrito em Delégua e bibliotecas ou APIs escritas em outras linguagens, como JavaScript.
